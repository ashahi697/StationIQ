# Station IQ
INFO4871 Final Project

Growing up in a family that owns and manages their own independent gas station and convenience stores there main thing that has always been annoying to me has been the software. My family currently uses a very outdated back office software and I often talked to my dad about upgrading but that obviously costs money. With this I wanted to make a more intuitive back office software my family can use instead of spreadsheets and pen and paper.

For my final project for INFO 4871-003, when we were discussing a full stack web app I thought this was something I eventually wanted to accomplish once I thought I had enough skill but after seeing how my bun buff project turned out I felt a little bit more confidence and actually chose to pursue this project and I hope this is something I get to continue building going into my final semester and beyond.

## The process

I created the basic HTML page using another one of our projects from our first project with the reading pages with the links to other pages. I wanted to focus on the things that matter most to running this business. Obviously you need your inside sale but you also need your outside sale in gallons which is why I have the dashboard, page which was built primarily with javascript, css, and html. I think the project looks decently impressive only because I took a lot of time on my CSS as I personally just find it satisfying to see the change. I learned how the cards work on css and had a blast making the dashboard again because I loved the aesthetics. With the sub pages so the pages for fuel and inventory I tied it all into my FastAPI code which let me store the data from my entries into json files.

## What I would change
I obsessed too much on the look of the web app that I didn't really even focus on making this as full stack as possible so I added things I believe would actually be useful. Adding in my inventory, fuel sales for the day, gallons per fuel grade. If I worked a little more diligently I would have made it to where I didn't use fake data for the dashboard and I can plug in my daily inputs to reflect on the holistic dashboard.
